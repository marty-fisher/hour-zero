## Roadmap & Future Scaling

INGESTION is evolving from a single-account experimental tool to a robust, multi-tenant analytical platform.

### Phase 1: Public-Facing Platform & "Building in Public" (Short Term)
*   **Frontend Display of Instagram Data:** Visualizing metrics and trends without exposing sensitive details.
*   **Methodology & Architecture Deep-Dive:** Public documentation on data ingestion, backend architecture (GCP/Supabase), and predictive modeling.
*   **Future Directions:** A living document of upcoming features and community-driven ideas.

### Phase 2: Data Science & Analytics (Medium Term)
*   **Automated Daily Reports:** Daily performance summaries.
*   **Predictive Modeling:** Time-series analysis for view prediction.
*   **Hashtag Correlation:** Impact analysis on reel velocity.

### Phase 3: Multi-Account & Scaling (Long Term)
*   **Multi-Tenant Tracking:** Support for multiple active reels across accounts.
*   **User Dashboard:** React/Next.js frontend for account management.
*   **Security & Infrastructure:** GCP Secret Manager, CI/CD pipelines, and comprehensive logging.
